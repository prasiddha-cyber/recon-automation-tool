# Recon Automation Tool

## Overview
This project is a Python-based reconnaissance and information gathering toolkit used during web penetration testing.

It automates multiple tasks commonly performed during the reconnaissance phase of security assessments.

## Features

- IP Scanner
- Port Scanner
- Barcode Generator
- QR Code Generator
- Password Generator
- Wordlist Generator
- Phone Number Information Lookup
- Subdomain Checker

## Technologies Used

- Python
- Socket Programming
- Requests Library
- QRCode Library
- Python Barcode Library
- Phonenumbers Library

## Project Structure

recon_tool/
- recon_tool.py

wordlists/
- subdomains.txt

requirements.txt
- Python dependencies

README.md
- Project documentation

## How To Run

Install dependencies:

pip install -r requirements.txt

Run the tool:

python recon_tool/recon_tool.py

This tool is developed for **educational purposes and ethical security testing only**.

Use it only on systems you own or have permission to test.
